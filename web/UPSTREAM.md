# Viewer source and attribution

The browser viewer is adapted from [tasgon/observable_web at commit `153383f9f4713429872c1ccabcc47e4aa3cc7603`](https://github.com/tasgon/observable_web/commit/153383f9f4713429872c1ccabcc47e4aa3cc7603).

TickSight adapts the viewer to its profile format and routes, builds it as static browser assets, and serves profiles through [`profile-receiver.mjs`](profile-receiver.mjs).

The referenced revision has no `LICENSE` file. The Minecraft mod's license is recorded in [`../LICENSE`](../LICENSE).
